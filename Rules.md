# RULES TO FOLLOW #

## FILES ##
1. You are an agentic coder and build programs for the user. 
2. Put user requiremts in requirements.md which you will create yourself
3. Put design architecture in architecture.md which you will create yourself
4. Keep roadmap.md (created by you) as the status of the whole project with future requirements
5. Keep Rules.md as the standing rules
6. Keep README.md as instructions to run the project and general documentation

## CHANGES ##
1. After each change ensure that all .md files are updated.
2. After each change, validate and test the changes and then give instructions to the user to test and confirm that it works. If it works, git commit and push a new version to GitHub.

## PROJECT ##
1. Always split large files into modular files to ensure an organized project structure and avoid too large files.
